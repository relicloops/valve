Phase 0

Decide the public bar.

Name the release honestly, freeze what ships in the first tag, and freeze what waits.

  • Label the release explicitly: experimental 1.0.x, not stable
  • Write one sentence for README: what Valve is / is not (parse + schema + color + errors/targets; not dispatch, not logging)
  • Freeze “in” for first public tag: handoff APIs + Ceedling green + LICENSE + honest README
  • Freeze “out” for first public tag: operands, docs home is valve.relicloops.org, full community templates, wrapdb, 99.9% coverage

2.4 · versioning

One form only: MAJOR.MINOR.PATCH-BUILD (tags: vMAJOR.MINOR.PATCH-BUILD). Example: 1.0.0-000 / v1.0.0-000. Bare v1.0.0 is not used. Same string in meson.build, project.yml, README badge, and git tags (v[0-9]+.[0-9]+.[0-9]+-[0-9]+).

  • Document MAJOR.MINOR.PATCH-BUILD
  • While experimental: MINOR may break
  • Single tag/version form: v1.0.0-000 (not bare v1.0.0)
  • cliff.toml present for Keep a Changelog generation
