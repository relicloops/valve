04 · presentation contract

The schema writes the help.

Valve infers accepted syntax from option type, value kind, target, and assignment mode. The caller may add usage guidance, but does not need to restate the signature, required state, requirements, reverse references, or conflicts.

rendering invariant 
signature
  + annotations
  + optional usage
  + optional description

one shared option renderer

Inference

.usage supplements; it does not override.

The visible <type> comes from the option's value model. Dot-notation options derive it from their target. Boolean flags render bare.

schema 
{
  .name = "limit",
  .type = VL_OPT_TYPE_LONG,
  .value = VL_OPTION_VALUE_INT,
  .usage = "Maximum rows returned.",
}
generated output 
--limit=<int>  [requires: --list]
    Maximum rows returned.
complete

Callers may omit .usage entirely. Valve still prints a correct option signature and every declarative relationship annotation.

Signature flow

Four schema decisions become one line.

Type controls the accepted spelling, value controls the label, assignment controls the separator, and relationship tables contribute annotations.

Automatic annotations

Both sides of every relationship are visible.

Requirement direction is preserved at runtime, but reverse help remains useful. Stable schema order and label deduplication keep the output deterministic.

forward view

  [requires: --id, --list]
reverse view 
--id=<string>

-- <command> [args…]
command position

A schema-declared command tail prints last in its scope, and targeted help plus relationship annotations use its real -- <command> [args…] syntax instead of inventing a named option.

Dot notation

Dotted option names are complete.

A dotted name is an exact option key and a grouping signal. It can populate a nested caller target, infer its displayed type, and drive both overview grouping and targeted group cards.

Target resolution

Help can focus without changing parse state.

Reserved help supports joined or separate targets according to assignment mode. Exact option names win before structural verb paths and group prefixes.

01 Read target

--help=target or --help target, with active-scope single-token resolution when no explicit target token follows.

02 Exact option

Dotted names such as proxy.lane match literally first.

03 Command path

Resolve verb, verb.subverb, verb.option, or verb.subverb.option.

04 Group prefix

A prefix such as proxy selects all visible proxy.* entries.

05 Render card

Use the shared renderer, including inferred syntax and relationships.
